能力

不只是多几列

从解析、筛选、预览，到 SSH 远程浏览、跨设备传输与作业队列 —— 整条计算流程都收在同一个窗口里。

01

15 个扩展名，一套解析

Gaussian 的 gjf / com / log / fch / fchk，ORCA 的 inp / out，XYZ、MOL、SDF，Molden、DMol3 与 cub 格点文件，统一走进 wmfold-core 的化学解析。

rswfn 驱动的元数据
02

类型筛选，表头跟着换

命令栏下方一排类型按钮：全部 / 高斯输入 / 高斯日志 / 量化输出 / 检查点 / XYZ / MOL / SDF / Molden / DMol / Orca / 格点。点一下只剩该类型，表头自动切换成该类型能提供的化学列。

每个类型的列都能单独配置
03

选中即有预览

单击文件，右侧面板列出完整信息：化学式、原子数、总电荷、多重度、α/β 电子、基组函数、分子量、能量。分隔条可以拖动，宽度会被记住。

预览 / 作业查询 双页签
04

远程机器，像本地一样浏览

在设置里添加 SSH 机器（密钥或密码都行），标题栏「+」打开它的标签页。首次连接会把静态 Linux 版上传到 ~/.local/bin，之后按远端 wmfold -cli 输出的 JSON 浏览。

每台机器独立的路径与筛选
05

跨设备复制粘贴

本机 ↔ 远程、远程 A ↔ 远程 B，复制 / 剪切 / 粘贴整份文件或整个目录都行；传输走 tar 流式管道，剪切在传完后删除源路径，大文件也不会被读进内存。

Ctrl+C / Ctrl+X / Ctrl+V
06

顺手看一眼队列

给远程机器启用「作业查询」，右侧面板就会定时执行配置的命令（默认 squeue -u $USER），空白分隔的输出自动排成表格，刷新间隔 5–600 秒可调。

squeue / qstat 都能用

资源管理器

它首先是一个称职的文件管理器

化学列只是加在熟悉界面上的东西。日常的文件操作一个都没有少，快捷键也按 Windows 的习惯来。

  • 面包屑地址栏，双击可直接输入路径；Alt+←/→ 后退前进，Backspace 上一级，F5 刷新
  • 列头排序（文件夹始终置顶）、当前目录搜索、类型筛选与计数
  • F2 重命名、Delete 删除（默认进回收站）、Ctrl+C/X/V 复制剪切粘贴、Ctrl+N 新建文件、Ctrl+Shift+N 新建文件夹
  • 机器标签可以拖出成独立窗口，再拖回去合并；标签右键也有「在新窗口打开 / 合并到主窗口」
  • Ctrl+` 在当前目录打开外部终端：自动 / Windows Terminal / PowerShell / cmd 可选
单一实例：重复启动只会把已有窗口提到前面，不会出现两个进程抢同一份配置。

远程与设置

计算在服务器上，浏览也可以

远程标签页和本地标签页长得一样：POSIX 路径、面包屑、排序、筛选、化学列、预览全都在。 只是每一条数据都来自远端 wmfold -cli 的 JSON。

  • 两种认证：不填密码走系统 OpenSSH 密钥；填密码则用随包的 PuTTY plink，密码经 DPAPI 加密后保存在本机，命令结束后立即删除临时密码文件
  • 自动装好服务端：首次连接把静态 Linux 版放到 ~/.local/bin/wmfold，之后复用缓存，不再反复握手
  • 快速访问按机器切换：每台机器有自己的「用户目录」与固定目录，固定项缺失时会灰显并标出「不可用」
  • 展示信息可调：每种文件类型勾选需要的列；另外可以显示隐藏文件、选择外部终端工具

支持格式

认识你常用的那些文件

文件类型由扩展名识别，内容交给 rswfn 解析；不同格式能提供的列不一样，界面上就只显示它对得上的那几列。

Gaussian

.gjf · .com · .log · .fch · .fchk

ORCA

.inp · .out

结构文件

.xyz · .mol · .sdf

Molden

.molden · .mde

DMol3 与格点

.dmo · .dmi · .cub

可用的化学列

化学式原子数电荷多重度α/β 电子基组函数分子量能量 (a.u.)
坏文件不会拖垮窗口：所有解析都经过 wmfold-core 的三层防护 —— 先对易崩溃的格式（gjf、log）做必要标记预检，再把读取包进 catch_unwind，最后失败即降级为「—」。这也是它永远不直接调用 Mole::from_file 的原因。

命令行接口

远程浏览，靠的就是这一个命令

桌面端的「远程机器」不是另写的一套协议：每一条目录数据都来自远端 wmfold -cli 输出的 JSON。 协议版本 1、结果单行输出、字段稳定，脚本和调度系统也可以直接拿去用。 

# 三个子命令，输出都是 JSON
wmfold -cli list ~/calc --chem
wmfold -cli info ~/calc/C6H6.xyz --chem
wmfold -cli version
// 解析出来的化学字段（entries[0].chem）
{
  "formula": "H6C6",
  "nAtoms": 12,
  "charge": 0,
  "multip": 1,
  "nBeta": 21,
  "nBasis": 216,
  "molW": 78.114,
  "energy": -232.24864864
}
输出不会被打扰：化学解析遇到坏文件时，panic 会被静默记录到临时日志，stdout 始终只有一行 JSON —— 这正是桌面端远程列表能直接解析的原因。
